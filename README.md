# Shared Living Platform

Semester project for Software Development Methodologies.

## Product idea

A platform for people living in shared accomodation to organize household responsabilities and participate in social activities.

## Product goal

Help people living in shared accomodation manage every household responsabilities and connect with others in one platform.

## Target users

- People living in shared flats
- Students and international students
- Landlords or property managers with limited access

## Main features

- Manage household tasks and cleaning
- Communicate between flatmates
- Upload evidence of completed tasks
- Manage shared household items
- Report maintenance issues
- Create and join social activities

## Main user journeys

- Flatmate household journey: manage shared responsibilities and household information inside the private flat space.
- Landlord journey: handle maintenance-related communication and follow reported issues.
- Social journey: discover, create and join activities.

## Initial risk

- The project scope may become too large for one semester.
- Image upload may add technical complexity.
- Different user roles may make permissions more complex.

## Out of scope

- Real-time chat.
- Payments
- Real-time maps
- AI recommendations
- Advanced social-network features
