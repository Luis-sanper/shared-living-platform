# Shared Living Platform

Semester project for Software Development Methodologies.

## Product idea

A platform for people living in shared accommodation to organize household responsibilities and participate in social activities.

## Target users

- People living in shared flats
- Students and international students
- Landlords or property managers with limited access

## Main ideas

- Manage household tasks and cleaning
- Upload evidence of completed tasks
- Manage shared household items
- Report maintenance issues
- Create and join social activities
