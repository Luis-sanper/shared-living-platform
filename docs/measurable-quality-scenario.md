# Measurable Quality Scenarios

## Performance

- After a successful login, the system should display the user's main dashboard within 3 seconds under normal usage conditions.
- When a user opens the household task list, the system should display the available tasks within 3 seconds under normal usage conditions.

## Security and privacy

- A user must not be able to access private information belonging to a flat they do not belong to or manage.
- Private content, such as private storage, private messages, and task photo evidence, must only be visible to the users authorized to access it.
